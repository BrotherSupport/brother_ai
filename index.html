FAQ

Brother AI 跟一般個人 AI 工具有什麼不同？

Brother AI 針對企業場景設計，包含知識庫整合、權限管理、審計紀錄與私有部署選項，而非單純的個人聊天介面。

可以自由選擇模型供應商嗎？

可以。透過 LLM Gateway，你能在 OpenAI、Anthropic、開源模型之間彈性切換，不被單一供應商綁定。

支援私有部署嗎？

支援。提供 SaaS、私有雲與 On-Premise 三種部署模式，資料可完全留在企業內部。

能整合現有系統嗎？

Agent Builder 支援與常見系統（如 Slack、Email、CRM）串接，並開放 API 供客製整合。

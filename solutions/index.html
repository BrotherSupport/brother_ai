AI Gateway

統一的企業級模型入口

集中管理不同模型供應商的 API 金鑰、用量與成本，並提供呼叫層級的紀錄與防護規則，一個 API 即可串接 6 家 LLM。

  • 多模型路由：OpenAI、Anthropic、開源模型可自由切換
  • BYOK（自帶金鑰）與集中式用量計量、成本控管
  • 主力模型逾時／異常時自動 fallback，呼叫層級 Guardrails 與可觀測性

Agent 自動化系統

把整段業務任務交給背景 Agent 執行

Agent 自動化系統由 CrewAI 驅動，使用者透過網頁介面定義任務、以 API 觸發，交由背景 Agent 執行並內建品質把關機制。原始碼開源於 github.com/BrotherSupport/agent_auto_system。

🧩

11 種任務類型

涵蓋表單提交、網頁爬取、試算表讀取、Email 寄送、PDF 報表產出、任務申請等場景，並可串成 Pipeline 依序執行多個自動化。

🔀

多 LLM 架構

每次執行可選擇 OpenAI、Anthropic Claude 或 Google Gemini，並依任務類型設定溫度參數；同供應商內建跨模型 fallback，應對短暫中斷。

🔄

自我校正執行

驗證層會依任務規則檢查每次結果；失敗時自動重新執行，並將前次錯誤訊息注入提示詞，讓 LLM 自我修正。

📊

獨立品質評分

由獨立 LLM 評審對每次結果進行 0–100 分評分並附上信心指標；評審模型與產出模型不同，避免分數虛高。

💰

資源與成本追蹤

完整記錄每次執行的 token 用量與美元成本估算，並可透過統計端點彙總分析。

⚡

非同步執行架構

後端採 FastAPI，立即回傳 202 並於背景執行；前端透過 SSE 每 0.5 秒更新即時進度，開發流程包含 380 組測試、mypy 型別檢查與 ruff 靜態分析。
